# Исходники проведенных экспериментов

В `recorded-source/` сохранены выбранные собственные реализации обучения,
декодирования и измерений, использованные в исследовании. Их SHA256 указаны
в манифесте; исходники перенесены без изменения.

- `gliner-training/`: полное дообучение и LoRA, фиксированная схема,
  выбор checkpoint/порога и оценка точных символьных границ.
- `gliner-adapters/`: DoRA, rsLoRA и частичное NF4-квантование с LoRA.
- `llm-ner/`: токенизация, повтор входа, новая BIO-голова и обучение LLM.
- `long-documents/`: последовательное сравнение полного текста и окон.
- `prompt-baseline/`: фиксированная генерация и строгий JSON-декодер.

Это исходники конкретных экспериментальных запусков. Они ожидают служебные
манифесты, каталоги моделей и конфигурации исходного комплекта; этот каталог
не является готовым автономным запуском всех опытов. Он позволяет проверить
детали алгоритмов и условия подсчета. Сводка выполненных опытов находится
в [протоколе](../docs/experiments.md), значения - в [результатах](../results/).

Для воспроизводимого учебного пути на опубликованном корпусе используйте
[переносимый пример](../docs/quickstart.md) и `src/`. Он подготовлен после
эксперимента; новые запуски не следует выдавать за источник опубликованных чисел.
Полные веса и состояния всех эпох в Git не включены. Базовая модель загружается
из закрепленной публичной ревизии по инструкции примера.
