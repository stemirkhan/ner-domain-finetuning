# Лицензии компонентов

Собственные скрипты, синтетические тексты, выбранная разметка и иллюстрации
в этом пакете опубликованы по MIT. Исходные тексты подготовлены агентом и
собраны генератором; разметка учителя получена для тех же синтетических текстов.
Независимой человеческой/отраслевой проверки корпуса нет.

## Шрифт

SVG содержат встроенный Neucha. Шрифт распространяется по SIL Open Font
License 1.1, его лицензия сохранена в `assets/fonts/OFL.txt`, происхождение -
в `assets/fonts/SOURCE.md`. MIT репозитория не заменяет лицензию шрифта.

## Модели и зависимости

Веса моделей и сторонние Python-пакеты не включены в репозиторий.
Закрепленная GLiNER2.5 Multi загружается с Hugging Face; ее карточка заявляет
Apache-2.0. Проверять условия получения и использования нужно по карточке
конкретной модели. Собственные веса Qwen/Gemma также здесь не распространяются.

Код использует API GLiNER2, PyTorch, Transformers, PEFT, NumPy и других
установленных зависимостей. Они сохраняют свои лицензии и не становятся
частью MIT-кода этого репозитория. В `experiments/recorded-source/` размещены
собственные обертки и исследовательские реализации; код библиотек не скопирован.

Названия Fastino, DeepSeek, Qwen и Gemma используются для указания
участвовавших моделей, без утверждения о поддержке проекта их разработчиками.
