разметка учителем, Qwen/Gemma с NER-головой и проверка длинных документов.

## Основные наблюдения

На коротком test из 1 000 текстов исходная GLiNER получила Exact F1 22,51%,
после полного дообучения — 94,13%, а на разметке DeepSeek — 95,62%.
У Qwen/Gemma с NER-головами получилось 79,48%/67,89%.

В отдельном длинном test все 16 NER-конфигураций обработали по 1 000 документов.
Лучший наблюдаемый общий Exact F1 — 93,36%, GLiNER после полного дообучения
на разметке DeepSeek, обработка окнами. На срезе 8K эта конфигурация дала
F1 93,78%, P50 404,95 мс и peak allocated 1,49 ГиБ.

Exact F1 требует точного совпадения типа и границ. Полное покрытие секрета
и сохранение публичных значений оцениваются отдельно. Например, у лучшего
длинного варианта полностью закрыта 471 из 480 секретных сущностей, но
задеты 13 из 480 публичных целевых значений.

Это описательное сравнение конкретных рецептов на зависимой синтетике,
с одним seed. Короткий и длинный test различаются и по содержанию;
разницу качества между ними нельзя приписывать одной длине текста.
Политика коммерческой закрытости задана для этого учебного примера.

## Попробовать обучение

Минимальный CLI в `src/` проводит путь от JSONL с символьной разметкой
до сохраненной модели, выбора на dev и маскирования нового текста.
Подробные команды, версии и требования — в [quickstart](docs/quickstart.md).

Этот переносимый пример подготовлен после эксперимента. Он демонстрирует
тот же тип задачи и настройки полного дообучения/LoRA, но не является
обещанием побитового воспроизведения опубликованных измерений.
В `experiments/recorded-source/` отдельно сохранены исходные реализации
экспериментальных запусков с контрольными суммами.

## Лицензии и происхождение

Собственный код и материалы репозитория распространяются по [MIT](LICENSE).
Встроенный шрифт Neucha — по [SIL OFL](assets/fonts/OFL.txt).
Базовые веса в Git не включены; GLiNER скачивается из закрепленной ревизии
[Fastino GLiNER2.5 Multi](https://huggingface.co/fastino/gliner2.5-multi-v1)
с собственной лицензией модели. Qwen, Gemma, PyTorch, Transformers, PEFT
и другие зависимости распространяются на условиях их правообладателей.

Хеши и преобразования экспортированных материалов описаны в
[data/manifests/source-published-hashes.json](data/manifests/source-published-hashes.json).
Составные исходные формулировки подготовлены агентом, тексты собраны
генератором; независимой человеческой экспертной разметки нет.
