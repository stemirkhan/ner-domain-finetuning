# Иллюстрации статьи

`figures/` содержит 17 изображений в PNG и редактируемом SVG:
семь схем, четыре графика и шесть таблиц. Рисованный стиль использует
Neucha, точечный фон и простые линии. Метрики взяты из
[единого снимка](../results/article-snapshot.json),
[таблицы в Markdown](../results/article-tables.md) доступны для копирования.

Таблицы `table-05-short-quality` и `table-06-long-quality` показывают
precision, recall, F1, полностью скрытые секреты и задетые публичные цели.
В статье первая заменяет прежний F1-only график `chart-01-short-f1`;
этот график сохранен для истории. [Полные числовые таблицы](../results/quality-metrics.md)
включают также две конфигурации с системным промптом короткого теста.

Встроенный в SVG шрифт Neucha распространяется под SIL Open Font License;
[лицензия](fonts/OFL.txt) и [источник](fonts/SOURCE.md) сохранены отдельно.
Эта лицензия шрифта не заменяется лицензией программного кода репозитория.
Изображения схем иллюстративны и не являются новыми ответами моделей.
