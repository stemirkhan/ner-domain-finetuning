# Языковые модели с NER-головой

Исходные базы: [Qwen/Qwen3.5-4B-Base](https://huggingface.co/Qwen/Qwen3.5-4B-Base)
(revision `1001bb4d826a52d1f399e183466143f4da7b741b`) и
[google/gemma-4-E2B](https://huggingface.co/google/gemma-4-E2B)
(revision `433813a669639fd7eaa83155828e9000ed357d53`).
Использованы только текстовые backbone без vision/audio и LM-head следующего
токена. Новая token-classification голова предсказывает 13 BIO-классов:
`O` и по `B`/`I` для шести типов. Код восстанавливает символьные границы.

LoRA адаптирует backbone, голова `score` обучается полностью. У Qwen адаптеры
охватывают attention и Gated DeltaNet; у Gemma учитывают совместное
использование K/V-проекций. Точный [конфиг](../configs/experiment-llm.json)
сохранен: три эпохи, microbatch 2×accumulation8, rank16/alpha32/dropout0,05,
BF16-base, FP32-adapters/head, LR `2e-4`/`5e-4`, cosine schedule, warmup5%.
Вес класса `O` в loss - 0,25, остальных - 1; seed20261114.

Текст сегментируется по словам, пробелам и пунктуации, затем каждый фрагмент
токенизируется. Вход содержит две копии с разделителем. Loss и итоговые
предсказания считаются только для второй: весь первый документ становится
левым контекстом. Attention mask остается каузальной. Контроль с одной копией
не выполнялся; эффект повторения отдельно не установлен.

По dev выбраны третья эпоха Qwen и первая Gemma, порог 0,95 обеих. На коротком
test F1 составляет 79,48% и 67,89%. Адаптеры не объединены с базой при inference.
Загружены около 4,21 млрд текстовых параметров Qwen и 4,63 млрд Gemma; E2B в имени
не означает общее число загруженных весов.

## Вариант только с промптом

Отдельно проверены instruction-checkpoint Qwen3.5-4B и Gemma4-E2B-it с одним
системным промптом, без NER-дообучения. Greedy `do_sample=False`, thinking
выключен, максимум 384 выходных токена, native chat template. Строгий JSON
не исправлялся и не ограничивался грамматикой. F1: 67,88%/15,18%.
У Gemma536 из 1 000 ответов имели невалидный JSON, включая Markdown-обертки.
Это результат выбранного prompt/decoder, не оценка лучшего достижимого
качества после настройки. Полная проверка качества охватывает 1 000 текстов;
latency - общие 200ID на одной RTX 5090. Источники для BIO и instruction разные.

На длинных документах основные prompt-only прогоны отменены автором;
их метрики сохранены как `null`, а не нулевой F1. [Результаты](../results/comparison.md).

[Сохраненные исходники запусков](../experiments/README.md) приведены как код
завершенного эксперимента. Маленький учебный CLI репозитория ориентирован
на GLiNER и не объявляется полным pipeline всех LLM-вариантов.
