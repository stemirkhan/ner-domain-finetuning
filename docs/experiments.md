# Что было выполнено

В репозитории опубликованы выбранные материалы завершенной серии опытов,
а также отдельный небольшой учебный CLI. [Сохраненные исходники реальных
запусков](../experiments/README.md) и учебный пример имеют разное назначение:
результаты ниже не приписываются новому упрощенному коду без повторного прогона.

## GLiNER и варианты дообучения

База: [`fastino/gliner2.5-multi-v1`](https://huggingface.co/fastino/gliner2.5-multi-v1),
ревизия `cf5593a5d45e3bbf204b9df621b13b1c0cf25ee3`, 287 355 159 параметров.
Архитектура boundary с mDeBERTa; загрузка через `AutoExtractor`.
На входе текст и общая схема шести типов, на выходе символьные границы.

Исходное обучение выполнено на RTX 3090 24 ГБ: 3 полные эпохи,
microbatch 2, накопление 8, эффективный batch 16, seed `20261114`,
BF16 autocast, AdamW, linear schedule, warmup 10%, weight decay 0,01.
Точные [конфигурации эксперимента](../configs/experiment-gliner/) сохранены
отдельно от конфигураций учебного CLI.

| Рецепт | Обучаемая часть | Выбранная эпоха | Порог |
| --- | --- | ---: | ---: |
| Исходная база | Без обучения | 0 | 0,95 |
| Полное дообучение | Все веса | 2 | 0,95 |
| LoRA | A/B в query/value энкодера | 3 | 0,90 |
| DoRA | A/B и magnitude-векторы | 3 | 0,90 |
| rsLoRA | A/B, масштаб alpha/sqrt(r) | 1 | 0,90 |
| QLoRA | A/B, часть базы в NF4 | 3 | 0,35 |
| Полное дообучение на разметке DeepSeek | Все веса | 3 | 0,60 |

У полного дообучения LR энкодера `1e-5`, остальных слоев `1e-4`.
У адаптеров LR `2e-4`, `r=16`, `alpha=32`, `dropout=0.05`.
GLiNER LoRA обучает только 589 824 A/B-параметра; task-слои заморожены.
DoRA обучает 608 256 параметров. QLoRA здесь квантует 72 линейных слоя
энкодера - около 29,6% исходных весов, а не всю модель; используется
NF4 с double quantization, обычный AdamW без paged optimizer.

Checkpoint и общий для типов порог выбирались на dev по строгому micro-F1;
при равенстве - меньше публичных ошибок, более ранняя эпоха и больший порог.
Сетка порогов `0.05, 0.10, ..., 0.95`. Сохраненные веса пилота не становились
стартом основного обучения. Новый метод начинал с исходной базы.

## Качество и скорость

[Таблицы результатов](../results/comparison.md) берут точные значения из
[компактного снимка](../results/article-snapshot.json). Полное совпадение типа
и символьных границ требуется для Exact F1. Полное покрытие секрета и
случайное маскирование публичной цели считаются отдельно.

Скорость всех девяти NER-конфигураций затем повторно измерена на одной
RTX 5090: batch 1, одинаковые 200 test ID после прогрева. Время включает
токенизацию, перенос на GPU и восстановление координат. Загрузка весов,
буквальная замена масок и запись результатов исключены. Старые времена
обучения RTX 3090 не смешиваются со скоростью inference RTX 5090.

LoRA/DoRA/rsLoRA GLiNER при inference объединены с базой. QLoRA остается
NF4 с неслитым адаптером; LLM с NER-головой тоже используют неслитые адаптеры.
Сравниваются эти рецепты, а не изолированное влияние имени метода.

Кроме GLiNER выполнены [Qwen/Gemma с NER-головой и prompt-only](llm-ner.md),
а затем [длинный тест](long-documents.md). В исходной серии окружение GLiNER:
Python 3.12, gliner2 2.1.0, Transformers 5.22.1, PEFT 0.21.2;
вариант QLoRA использует bitsandbytes 0.50.2. Точные поколения PyTorch/CUDA
различались: обучение GLiNER - torch 2.15.0+cu132, поздний RTX 5090 -
2.10.0+cu128. Учебный CLI описывает свое окружение отдельно.

## Пределы

Один seed и композиционная синтетика не устанавливают устойчивый рейтинг.
Расширения короткой серии выполнялись после просмотра прежнего test;
общего нового слепого теста всех систем эта серия не дает. Инструкции и
пороги не подбирались по итоговым ответам соответствующих запусков.
Производственный поток и независимая экспертная разметка не проверялись.
